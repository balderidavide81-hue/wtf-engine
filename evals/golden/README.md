# Golden evaluation set

This folder will contain real candidate stories with human labels.

Initial target: 100–150 examples covering KEEP, MAYBE and REJECT, including:
- weird but boring;
- funny but weakly sourced;
- verified completed WTF;
- future event with objective resolution;
- normal-looking story with strong Predict potential;
- tragedy/sensitive content that should not be gamified.

The user's "I would play/share this" judgment is the primary product label.
